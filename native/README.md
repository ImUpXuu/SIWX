# SIWX 原生功能删减版

以仓库中的原 SIWX 5.2.0 页面和后端为基准，直接保留原生聊天、消息媒体、朋友圈、导出、首启向导、设置、日志与提取解密缓存。不再使用 `safe/` 的页面或数据适配器。新版版本为1.6.1，原版脚本和5.2.0原始分发入口保持独立。

`python native/prepare.py` 生成 `_build/siwx`；原 `siwx/` 不改动。`native-source-manifest.json` 逐文件记录原SHA、生成SHA及删除。密码算法、提取、导出、朋友圈、媒体与向导文件与源文件逐字节相同；聊天页只去统计按钮、弹层和处理代码，其余会话/分页消息/富文本/媒体逻辑保持原生。移除聊天统计、备份、MCP、在线更新和推广信息。许可证与原作者法律条款保留。插件机制保留，但不能重新注册移除功能的URL。

原生服务仅监听127.0.0.1，不校验客户端IP、Host、Origin、Sec-Fetch、token或密码。保留原始路径和请求参数校验。微信进程范围只限启动它的同一Windows用户。

构建：安装requirements，执行prepare，再运行 `python -m PyInstaller --noconfirm --clean native/native.spec`。启动：`python native/app.py --host 127.0.0.1 --port 8787 --no-open`；脚本仍采用原WSH/CMD与选定桌面用户链路。`--data` 将目录交给原数据源管理保存。

存储：仅新版 `%LOCALAPPDATA%/stories-in-wx-console/native`，其中 `data` 存原生DPAPI密钥缓存/设置，`output` 存原生解密数据库；不使用旧原版默认 `stories-in-wx` 目录，不自动迁移旧原版数据。`SIWX_NATIVE_HOME` 可显式指定新版本地绝对根目录（也供隔离合成测试使用）。微信源库只读；清理缓存仍需原页面用户操作确认。

验证必须通过原生Flask API和真实页面模块读取合成SQLite、点击会话显示消息、筛选、分页、时间线与导出；FakeSource成功不能作为本版本聊天正常的证明。真实设备提取/媒体可用性仍需实际运行确认。1.4.2的适配修补构建未发布，不作为本版本实现。

保留AGPL-3.0许可证及源代码，发行时同时附完整对应源、差分生成器和构建说明；设置页提供本机对应源码下载，不依赖外部推广链接。


1.5.1修复：Windows自动发现逐个跳过返回OSError的盘根和Users目录（例如映射盘凭据失效WinError1326、权限拒绝或设备离线），继续检测其他盘/本人默认目录与手工配置；不会登录映射盘、修改密码或吞掉整个账号发现结果。网页原接口/页面与提取算法不变。

更新时重新运行在线独立脚本命令获取最新固定版本。版本变化自动下载新的ZIP，验证ZIP、清单和全部文件后使用新的版本目录；原版本文件不覆盖。不从旧窗口缓存的脚本获取更新。


1.5.2监听调整：入口默认并且仅接受127.0.0.1，独立脚本的启动、进程匹配、端口探测和输出地址均使用回环。网页功能与无客户端鉴权保持。只能在本机访问，或者由同一电脑上的反代/穿透客户端转发到127.0.0.1:实际端口（默认8787）；其他机器上的代理不能直接连接电脑局域网IP。软件不创建局域网/公网接口监听、不添加防火墙规则或关闭通知；实际设备第三方安全软件提示行为仍需实机确认。升级需停止旧0.0.0.0后台并打开新地址，旧进程不会因下载新版自行改变绑定。


1.6.0：原导出页面追加“已导出文件”，直接读取持久 exports 目录，展示文件名、相对路径、格式、大小、时间，支持搜索、分页、刷新与下载。每3秒自动刷新；刷新网页、重启或更新后仍读取同一路径，删除磁盘文件后同步消失。不恢复已移除的加密备份模块；不额外复制聊天数据。链接/目录跳转和越界下载被拒绝。独立脚本增加菜单16端口诊断，并可识别受保护安装路径中全清单SHA验证通过的1.5.0/1.5.1/1.5.2旧版；还须同SID、会话、精确命令、创建时间和原句柄复核。TCP连通只作诊断，其他程序占用保留并选择备用端口。


1.6.1：新增文件历史请求沿用浏览器同源登录凭据，兼容既有Basic认证反代（如wechat域名）；程序本身仍不添加鉴权。
