# SIWX × wexport：命令行启动、网页控制

按用户2026-11-02最新要求：不做独立桌面UI，不自动打开浏览器；用命令行启动，
网页控制本人Windows微信4.x自动提取、查看、搜索、导出和停止。
聊天统计、加密备份和MCP继续取消，不进入构建产物。

## 启动与使用

完整解压 `siwx-lite-windows-x64.zip`，保留 `_internal` 目录，在本人Windows桌面终端运行：

```powershell
.\siwx-lite.exe
```

默认监听 **0.0.0.0:8787**，表示本机所有IPv4网络接口；0.0.0.0不是浏览器访问地址。
命令行会列出本机网址和当前网络IP网址，手动打开其中一个，无令牌、不用登录。
浏览器选择账号，勾选本人数据确认，点击“提取并打开”，然后选会话、搜索和导出。
保持本人微信4.x登录并打开一段聊天；网页“退出并停止”或终端Ctrl+C结束程序。
关闭浏览器本身不会停止服务。程序没有安装后台任务、修改防火墙或创建公网映射。

找不到其他盘的账号，可指定**包含db_storage的账号目录**：

```powershell
.\siwx-lite.exe --data 'D:\example\xwechat_files\user_example'
.\siwx-lite.exe --host 0.0.0.0 --port 8787
```

仅本机使用可显式 `--host 127.0.0.1`。指定端口被占用会报错，不结束其他进程、不静默换端口；
需要临时空闲端口时显式 `--port 0`，以实际输出为准。兼容旧参数`--no-open`，当前始终不自动打开浏览器。
网页使用数字IP；机器网络接口变化后需重启重新生成允许Host列表。本版未配置域名反代Host或TLS。

## 无鉴权的含义

用户明确选择**取消随机令牌且不设置账号密码，允许可连接端口的设备直接访问**。
因此任何能连接端口的设备都可列出账号、触发提取、读取/搜索/导出当前聊天、关闭数据或停止程序。
HTTP未加密。Host/Origin/跨站检查只限制部分浏览器请求，**不是认证或网络访问控制**；
同网或通过转发可达的其他程序仍可调用接口。此版不能称“仅本人能看”或“安全远程访问”。

网页不能指定任意文件路径或执行命令，只能选择启动时发现的账号列表；
自动提取限定为当前运行用户自己的微信进程。本人数据确认只表达操作意图，不是身份认证。
本轮没有在用户电脑上开端口、改系统安全设置或部署此包，源码配置不等于已经对外运行。

## 功能与数据边界

- 保留：微信4.x现有只读自动提取、本机/网络网页浏览与关键词/日期搜索、
  HTML/Markdown/TXT/CSV/JSON五种文本导出、引用与合并转发摘要。
- 取消：聊天统计、加密备份、MCP、插件、自动更新、LLDB/Hook/注入、深扫、图片密钥扫描、
  SYSTEM桥接、计划任务、开机常驻、桌面UI和浏览器自动打开。
- 仅Windows微信4.x；不支持3.x/macOS/Linux的自动提取。账号发现只查本人常用目录和当前用户注册表，
  不全盘搜。保持本人桌面用户运行，不使用旧SYSTEM一键入口。
- 密钥和解密库只存内存，不显示密钥、不提供密钥API、不生成密钥缓存或明文库备份；源库只读。
  系统分页/崩溃转储不在应用控制范围；导出的聊天文件为明文，浏览器下载自行保存。
- 图片、语音、视频和附件只展示类型占位，不恢复媒体、不下载朋友圈或CDN。
  分库失败显示部分可用，不承诺记录完整；最多十万条匹配消息，超限需缩小日期范围，不静默截断。
- 沿用wexport原SQLCipher页头/WAL读取，未做完整逐页HMAC校验，不把解密成功等同完整性认证。

## Defender与McAfee

沿用原有只读提取实现，未修改算法或扩大进程访问权限，未添加混淆/免杀处理。
保留读取微信进程能力仍可能被Defender或McAfee检测；未配置代码签名，不保证零告警。
实际杀软与真实微信提取须针对准确构建/哈希另行验证，合成测试和构建成功不能替代。

界面`live_ui/`，导出`documents.py`。`live.spec`白名单保留MIT wexport原始只读模块，

```powershell
python -m pip install -r requirements-live.txt
python live_app.py
python -m unittest discover -s tests -v
```
